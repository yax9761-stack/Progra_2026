# Programación primer año

Las carpetas que van a visualizar en este repositorio son un conjunto de ejercicios y proyectos que he llevado a cabo en mi primer año de programacion.

## Carpeta numero 1: PseInt
Esta seria la primera carpeta que visualizarian en esta carpeta existen 70 ejercicios los cuales estan divididos en carpetas de 10 ejercicios y estan realizados para el psudocodido PseInt en el cual se veran ejercicios que iran variando acerca de: 
* Tipos de datos
* Tipos de operadores (logicos, Aritméticos, Relacionales o de Comparacion y de Asignación )
* condicionales (Si, Si no, Si no si).
* bucles (Para, Repetir, Mientras).
* arreglos y arreglos bidimensionales (arrays y matrices).

## Carpeta numero 2: HTML y CSS
Al terminar de visualizar la parte de la logica de PseInt veremos lo que es la estructura y el diseño de una pagina web veran diferentes ejercicios y cada vez va mejorando la parte del diseño web hasta acabar con paginas mucho mejor estructuradas las cuales tienen respondividad (todas estos ejercicios de paginas son solo estaticas).

Algunas de las herramientas que veremos seran:
* Tipos de etiquetas
* Maquetacion web
* Creacion de tablas
* Tipos de selectores
* Como utilizar display
* Tipos de Psudoclases
* responsividad

## Carpeta numero : JavaScript
Terminando con las carpetas siendo esta la ultima carpeta en esta carpeta veran lo que sera entrar a un lenguaje de programacion completo aca se ven temas los cuales ya se conocen por la logica que se desarrollo con PseInt tambien se veran nuevas herramientas que complementan y son de gran ayuda para desarrollar los diferentes codigos/algoritmos que nos pidan a continuacion veremos una lista de las nuevas herramientas que vimos en JavaScript:
* Nuevos Tipos de datos (symbol, Big Int, null, undefined)
* tipos de variables (Let y const)
* Bucles
* Tipos de funciones
* Recursividad
* Arrays y matrices
* Tipos de metodos
* objetos, Prototipos y funciones constructoras
* clases y herencia
